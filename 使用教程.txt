AutoArchive 汽修档案管理系统 · 使用教程
======================================

本机运行、离线可用；管客户/车辆/工单/图片/库存/收款，数据整包可携带。


一、启动
--------
- 双击 AutoArchive.exe 即可打开，无需安装、无需联网。
- 首次启动自动创建数据目录（默认 D:\database；无 D 盘则放到"文档/本地汽修档案数据"）。


二、数据 = 一个文件夹（最重要）
------------------------------
- 所有业务数据 + 图片 + 附件都在数据目录里（默认 D:\database）。
- 整包备份：把这个文件夹拷贝/压缩，就是完整备份；拷到别的电脑即可继续用。
- 右上角「备份」：一键打包成 归档系统备份_日期.zip 到 U盘/硬盘。
- 右上角「切换数据目录」：换用另一份数据或存放位置。


三、最常用：开单（接待新客户）
------------------------------
顶部点「开单」，全程一个页面完成：
  1. 客户框 ＋新建客户：填姓名、手机号 → 自动选中。
  2. 车辆框 ＋新建车辆：填车牌、品牌/车型（里面的"车主"也能＋新建客户）→ 自动选中。
  3. 接待框 ＋新建：填员工姓名、角色（店主/技师/前台）。
  4. 选工单类型（保养/维修/改装/检查）、填备注 → 创建并进入编辑。


四、工单详情
------------
- 改基本信息、类型、技师（可多选）。
- 添加施工项目（工时费）与使用配件（从库存选，自动显示库存提示）。
- 上传施工照片（施工前/中/后/故障）。
- 按类型填专属信息：保养→机油/下次保养；维修→故障码/方案；改装→品牌/序列号。
- 打印 / 导出 PDF：先弹 A4 预览，再选"打印"或"导出 PDF"（导出自动打开，并存入左侧附件）。
- 收款：填金额、付款方式，收款后工单自动完成，联动更新车辆/库存/统计。

工单状态：草稿 → 待施工 → 施工中 → 待验收 → 待收款 → 已完成；可 取消/退款。


五、其他功能
------------
- 仪表盘：今/月工单数、营收；库存预警；保养/保险/年检到期提醒（点忽略可隐藏，右上角恢复）。
- 客户 / 车辆管理：侧边栏「档案」折叠组里，可增改删、搜索；车辆 → 「档案」看时间轴（工单+照片+统计）。
- 配件库存：入库/出库/盘点（记流水），低于最低库存自动预警。
- 报表：营业/客户/车型/保养/库存，可导出 CSV/Excel。
- 设置：店铺名称、提醒提前天数、技师/操作人管理、数据目录。


六、常见问题
------------
[换电脑] 把整个 AutoArchive 文件夹 + 数据文件夹 一起拷过去即可。只拷程序 = 新电脑是空档案。
[限制] 仅适用于 64 位 Windows（Win10/Win11）；苹果 Mac、Linux、手机、老 Win7 不支持。
- 数据在哪：默认 D:\database；可在设置/右上角查看、切换。
- 忘了一辆车：「档案 → 车辆管理」或仪表盘提醒点进时间轴，看全部历史。
- PDF 打不开：确认系统有默认 PDF 阅读器；也可在工单「附件」里点「打开」。
- 数据安全：建议定期右上角备份到 U盘/移动硬盘。
